# 📱 Android 24/7 Background Setup Guide
### *Ensure 100% Uptime for Netfie Remote Agent on Any Android Handset*

To send SMS without interruption 24 hours a day, Android's built-in aggressive battery managers (Doze Mode, RAM cleaners) must be configured to never sleep or kill the **Netfie Bulk SMS Gateway** app.

Follow these brand-specific steps:

---

## ⚡ 1. General Android Settings (All Brands)

1. **Disable Battery Optimization**:
   - Go to **Settings → Apps → Netfie SMS Gateway → Battery**.
   - Select **Unrestricted** or **Don't Optimize**.
2. **Enable Autostart / Launch in Background**:
   - Allow the app to start automatically when the device boots up.
3. **Keep WiFi / Mobile Data Always On**:
   - Settings → Network & Internet → Ensure data saver is turned **OFF** for Netfie.
4. **Lock App in Recent Apps (Recents Screen)**:
   - Open Recent Apps overview.
   - Swipe or long-press the Netfie card and tap the **Lock 🔒** icon so it never gets cleared by "Clear All".

---

## 📱 2. Xiaomi / Redmi / POCO (MIUI / HyperOS)

Xiaomi has the strictest background killer. Apply all three:
1. **Autostart**:
   - Settings → Apps → Permissions → **Autostart** → Toggle ON for **Netfie**.
2. **Battery Saver**:
   - Settings → Apps → Manage Apps → Netfie → **Battery Saver** → Choose **No Restrictions**.
3. **Lock in Task Switcher**:
   - Open Recent apps → Long press Netfie → Tap the **Lock icon**.

---

## 📱 3. Samsung (One UI)

1. **Never Sleeping Apps**:
   - Settings → Battery and Device Care → Battery → **Background Usage Limits**.
   - Tap **Never Sleeping Apps** → Add **Netfie**.
2. **Turn off Adaptive Battery**:
   - Settings → Battery → More Battery Settings → Turn off **Adaptive Battery**.
3. **Lock in Recents**:
   - Open Recent apps → Tap Netfie app icon → Choose **Lock this app**.

---

## 📱 4. Realme / Oppo / OnePlus (ColorOS / OxygenOS / Realme UI)

1. **App Battery Management**:
   - Settings → Battery → Advanced Settings → App Battery Management → Netfie:
     - Allow Foreground Activity: **ON**
     - Allow Background Activity: **ON**
     - Allow Auto-launch: **ON**
2. **Lock in Recent Apps**:
   - Open Recent apps screen → Tap the 3 dots on Netfie card → Select **Lock**.

---

## 📱 5. Vivo / iQOO (Funtouch OS / OriginOS)

1. **High Background Power Consumption**:
   - Settings → Battery → **Background Power Consumption Management** → Find Netfie → Select **Allow High Background Power Consumption**.
2. **Autostart**:
   - Settings → More Settings → Applications → **Autostart** → Enable Netfie.

---

## 🔌 Best Hardware Recommendation for 24/7 Hosting:
- Keep the phone connected to a safe charger or smart plug.
- Use a phone running Android 9.0 to 14.0 with Dual SIM capability.
